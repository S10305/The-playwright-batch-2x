## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/S10305/The-playwright-batch-2x.git
   ```

2. Open the folder in [Visual Studio Code](https://code.visualstudio.com/).

3. Run JavaScript files with Node.js:
   ```bash
   node javascript_keywords_demo.js
   node identifier_rules.js
   node comments_examples.js
   ```
