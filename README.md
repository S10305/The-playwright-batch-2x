# The Playwright Batch 2x

A learning repository covering JavaScript basics, identifiers, literals, and developer tooling.

## 📁 Repository Structure

```
.
├── index.html                              # Main HTML file
├── .vscode/
│   └── launch.json                         # VS Code launch configuration
│
├── The playwright batch 2x/
│   └── Chapter_01_Basics/
│       ├── 01_Basics.js
│       ├── 02_JS.js
│       ├── 03_JS_Verifysetup.js
│       ├── 04_HotCode.js
│       ├── 05_JS Basics.js
│       ├── 06_IdentifierRules.js
│       ├── 07_IdentifierPart2.js
│       └── 08_comments.js
│
├── Chapter_03_identifier_Literls/

│
├── javascript_keywords_demo.js             # Reserved keywords examples
├── identifier_rules.js                     # Identifier naming rules
└── comments_examples.js                    # Different types of comments
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/S10305/The-playwright-batch-2x.git
   ```

2. Open the folder in [Visual Studio Code](https://code.visualstudio.com/).

3. Run JavaScript files with Node.js:
   ```bash
   node javascript_keywords_demo.js
   node identifier_rules.js
   node comments_examples.js
   ```
