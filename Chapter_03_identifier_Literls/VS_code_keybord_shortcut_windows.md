# VS Code Keyboard Shortcuts - Windows

## Keyboard Shortcuts Editor
| Action | Shortcut |
|--------|----------|
| Open Keyboard Shortcuts | `Ctrl + K` `Ctrl + S` |
| Open Default Keyboard Shortcuts JSON | `Ctrl + K` `Ctrl + R` |

## View & Panel Toggles
| Action | Shortcut |
|--------|----------|
| Toggle Sidebar (Explorer) | `Ctrl + B` |
| Toggle Panel (Terminal/Output) | `Ctrl + J` |
| Toggle Terminal | `` Ctrl + ` `` |
| Toggle Full Screen | `F11` |
| Toggle Zen Mode | `Ctrl + K` `Z` |
| Toggle Word Wrap | `Alt + Z` |

## Editor Layout (Split View)
| Action | Shortcut |
|--------|----------|
| Split Editor Right | `Ctrl + \` |
| Split Editor Down | `Ctrl + K` `\` |
| Close Editor | `Ctrl + W` |
| Reopen Closed Editor | `Ctrl + Shift + T` |

## File Explorer View
| Action | Shortcut |
|--------|----------|
| Focus Explorer Sidebar | `Ctrl + Shift + E` |
| Focus Search | `Ctrl + Shift + F` |
| Focus Source Control | `Ctrl + Shift + G` |
| Focus Extensions | `Ctrl + Shift + X` |

## Navigation
| Action | Shortcut |
|--------|----------|
| Quick Open (Go to File) | `Ctrl + P` |
| Go to Symbol in File | `Ctrl + Shift + O` |
| Go to Symbol in Workspace | `Ctrl + T` |
| Go to Line | `Ctrl + G` |
| Go to Definition | `F12` |

## Editing
| Action | Shortcut |
|--------|----------|
| Copy Line Down | `Shift + Alt + Down` |
| Copy Line Up | `Shift + Alt + Up` |
| Move Line Down | `Alt + Down` |
| Move Line Up | `Alt + Up` |
| Delete Line | `Ctrl + Shift + K` |
| Insert Line Below | `Ctrl + Enter` |
| Insert Line Above | `Ctrl + Shift + Enter` |
| Toggle Comment | `Ctrl + /` |
| Format Document | `Shift + Alt + F` |

## Multi-cursor
| Action | Shortcut |
|--------|----------|
| Add Cursor Below | `Ctrl + Alt + Down` |
| Add Cursor Above | `Ctrl + Alt + Up` |
| Add Cursor to Line Ends | `Shift + Alt + I` |
| Select Next Occurrence | `Ctrl + D` |
| Select All Occurrences | `Ctrl + Shift + L` |

## Debugging
| Action | Shortcut |
|--------|----------|
| Start Debugging | `F5` |
| Stop Debugging | `Shift + F5` |
| Restart Debugging | `Ctrl + Shift + F5` |
| Toggle Breakpoint | `F9` |
| Step Over | `F10` |
| Step Into | `F11` |
| Step Out | `Shift + F11` |

---

**Tip:** Press `Ctrl + K` `Ctrl + S` to open the Keyboard Shortcuts editor and search for any command.
